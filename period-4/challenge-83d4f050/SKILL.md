# 生物机制图与通路图

版本 0.1.0。适用范围为正常生理及基础生物学的教学表达。计算或实验结论来自输入材料。依据题目选择输出语言、信息密度、交付格式和图面尺寸。

## 接单

1. 平台执行时，读取 `/input/task.md`、`/input/case.json` 的全部字段和列出的材料。记录 `case_id`、源文件版本和原样的 `output_contract` 字段。用 `/app/work` 作工作区，用 `/app/output` 交付。先写可解析的阶段性 `result.json`，随实物和检查更新。
2. 阅读实际原文。优先定位到印刷页、图号及分面、图注、表或原始数据列行。扫描件同时检查页面图像。定位只有摘要时明确写摘要。文件缺失、文字无法判定及导出失败分别记录。图版中的定量关系只使用实际输入数据并保留单位、条件和映射。
3. 将名称消歧到物种、实体类别、亚型、复合物/亚基或活动状态。为实体、区室和相互作用分别记录定位。边的主语、客体、方向、作用对象、证据强度逐项取自材料。把实验物种、细胞类型和条件与教学综合的适用范围一起写清。

## 生成或修订

本目录中的 [绘图规格](references/graph.md) 定义了定性图的 JSON 图稿模型和最小调用例。先写证据表和关系表，再增加坐标。稳定的 ID、证据和箭头样式由同一模型写入可编辑 SVG。SVG 与模型一并交付。

- 用包含框表示空间区室。横截面中的跨膜实体可跨膜带，外周蛋白应在相应膜面，胞质分子在胞质。运输边穿相应边界并标明物质及两侧。路线先画主通路，再布分支和反馈，保留足够转折空间。
- 区分活化、抑制和关联。形状说明边的方向和符号，明确动词说明过程。抑制或减少必须指明受影响的是活性、水平还是通量。对于证据只支持关联的情况使用无箭头连线。方向有依据但属于综合推断时标虚线并说明依据。证据不足的边记录在不确定性里。
- 编辑任务先检查原图可编辑性并保留原件。用元素 ID 定位请求的改动。优先在当前 SVG 的对象和文本上编辑，保留图层、无关样式、数据和来源。非本工具生成的 SVG 可使用现有编辑器或 XML 工具。源文件为位图时，说明编辑能力的限制及实际重建的范围。
- 使用 `python scripts/pathway.py draw GRAPH.json FIGURE.svg` 生成原生矢量元素。命令从本 Skill 目录运行。平台工作目录下可调用 `/skills/weekly-skill/scripts/pathway.py`。按绘图规格导出 PDF 和 PNG。定量图、复杂原稿或特殊图元可用环境已有的矢量工具完成，证据、修改及导出检查随实物交付。

## 验收

打开实际导出的 PDF 和 PNG。逐条检查节点类别和区室、箭头端点和方向、图例、可视数据与原始数据、裁切、交叠、字符、尺寸和颜色。复核 SVG 里仍有可单独修改的文字和图形，并抽查关键元素的来源。修订后对比实际图元和导出，记录变更的 ID、修改前后值、请求和核验结果。

`result.json` 保留原始合同中每个输出字段及 `case_id`。由实际文件和观察填入状态、主结果、产物相对路径、证据定位、版本、导出参数和检查、修改记录及不确定性。标明哪些结论由材料推断，哪些项目尚缺材料或工具。若某个导出不可用，保存已完成的源文件并记录问题。只将运行中实际生成的文件列为产物。
