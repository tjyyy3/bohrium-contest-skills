# 科研关系图绘制与源图修订

## 先确定图意

读实际材料和工作单。平台运行时先读 `/input/case.json`、`task.md` 和工作单点名的源文件。以文件内容确认实体、单位、输入输出、顺序和包含关系。按对象 ID 记下来源文件及页码、章节、表格单元格或源图对象，再列出每条关系的 **起点 → 终点、语义、证据**。把材料支持的关系与仍需确认的关系写清楚。遇到冲突并列记录证据，暂缓画确定箭头。颜色、端点形状与线型有语义时逐项对照图例。数值或分类来自表格时保留表格行列、单位和映射，使用相应的数据驱动图表工具。

## 生成或修订

- **新图** 先按来源填实体、关系和样式，检查每条路径末端落在目标实体。小型矩形关系图用 `schematic.py create`，文件字段和最小调用见 [调用指南](GUIDE.md)。SVG 用独立图层、带 ID 的节点和连接、原生文字和路径。复杂容器、非箭头端点及其他图型可在可编辑图形工具中使用案例需要的原生对象。
- **已有图** 保留原件并先识别编辑目标、允许变动的属性和需要保留的对象。对于 ID 唯一且文本结构简单的 SVG 标签，以实际源图为输入执行 `schematic.py edit`，同时提供旧值和新值。一并修改所有获准变化的同类标签时逐项列出 ID。脚本保留标签正文以外的字节。涉及 `tspan`、容器、路径或其他源格式时，在原格式副本中编辑对应对象，核对对象树、样式及必要的关联变更。
- 把工作文件放在 `/app/work`，把实际源图、导出件和 `result.json` 放在 `/app/output`。脚本以本技能目录中的路径调用，平台安装根目录为 `/skills/weekly-skill`。

## 导出并复核

按案例给定的画布、字体、色彩和分辨率，从最终源图导出。默认 RGB、300 dpi PNG。优先使用能保留原生矢量与文字的渲染器。随附的 `export_svg.py` 使用 Chromium 将同一份 SVG 打印为 PDF，并把该 PDF 渲染为 PNG。调用、依赖和备选导出命令见 [调用指南](GUIDE.md)。

1. 按源材料复核实体名、数值、单位、关系方向、分组边界与图例映射。对修订比较修改前后对象 ID、文案、绑定端点、箭头位置和样式，确认差异落在工作单许可范围内。
2. 打开最终 SVG 和实渲染 PNG 或 PDF 页面，检查字形、裁切、标签溢出、交叉和缩小后的可读性。检查 PDF 页尺寸、矢量对象、字体嵌入与文字提取，检查 PNG 像素尺寸、分辨率元数据和色彩。记录实测及未验证项目。缺字时选择可用的覆盖字体，再渲染复查。
3. `result.json` 保留原样例的 `case_id`，按其 `output_contract` 原字段及类型提交主结果、实际文件、元素来源定位、状态、不确定性、变更与导出检查。缺材料记缺失，证据冲突记无法判定，渲染器失败记导出失败。保留可用的部分成果，只列实际生成且可读的文件。
