# 判定与复算规则

从实际比较选择条件。规则负责解释证据；稿件、方案和数据负责提供事实。

| 检查面 | 可复核操作 | 影响与处理 |
|---|---|---|
| 研究设计 | 从抽样/分配过程判定设计，核对对照、时间顺序、随机/盲法的对象、偏倚机制与主终点。比较方案和成文，检视观察性关联被写成因果、事后亚组被当验证性、抽样范围被外推的具体一句。 | 说明哪个偏倚会影响哪个估计、方向是否可知。随机化或盲法漏报只证明信息缺失；定性研究按招募、分析过程与证据支持来判断。 |
| 变量 | 从操作性定义追到表格和模型，核对暴露、结局、协变量编码、参照组、单位、切点及来源、测量时点和缺失码。区分变化值与末次值、率与比例、百分比与百分点。 | 找出首次出现分歧的字段。仅在同一量纲、计量口径和时间窗下转换。请求变量字典或明确映射，注明受影响的结果行。 |
| 统计方法 | 确认独立单位和同一对象内相关；看模型如何处理重复测量、批次、匹配与聚类。按变量类型、估计目标、残差/差值的分布假设、事件与删失选核查点。对亚组差异查交互检验，不从一组显著另一组不显著推断组间差异。 | 配对设计可用差值、配对分析或有效的相关结构模型。行数不等于独立单位数；如果方法只写“t 检验”先查 df、图例与脚注，再决定待复核或已证实。诊断图/数据未供时不可直接断言偏态或模型失效。 |
| 样本量 | 追踪计划→分配/招募→测量→分析的各组分母、失访与排除原因，区分独立重复与技术复测。设计阶段核对主终点、目标差异及来源、方差/基线率、α、单双侧、效能、分配比、聚类/失访膨胀及实际偏差。 | 给出能复算的参数和缺口。小样本本身不足以断言无效；用实际区间宽度说明精度。便利样本、固定历史资料或探索研究可说明可用样本与精度，避免要求事后“观察效能”。 |
| 结果报告 | 找主要效应的方向、单位、效应量、区间水平、p 的精度、统计量和 df。比图表与正文时配准时点、估计尺度、调整、受试/器件集、模型与多重性。 | 采用下列数值规则；报告原始、重算及允许误差。如果两处口径不一致，说明缺失的定义，避免判错。 |

**多重性与敏感性。** 列出假设族、预设主次、探索/确认用途和调整策略。单一预设主比较并不因表中有描述性指标而必需校正。多个独立宣称成功的确认性检验，核对错误率控制、顺序或联合成功标准；未见方案先请求方案。区分原始和校正 p 值。针对实际威胁（排除、缺失、模型设定等）提出具体敏感性分析，写明各分析应保持一致的估计对象；无法判定偏倚方向时明示不确定。

**数值可比性。**

- 比例先确认互斥、是否多选、是否加权、分母及缺失。整数计数未加权时，`check.py percent 分子 分母 报告百分数` 按最后展示的小数位构造舍入区间，边界保守纳入；输出 compatible 只表示算术相容。报告值用字符串输入，保留末尾 0。对存在误差的其他输入同时传播其舍入范围。
- 同一估计、模型、对比、分析集、双侧检验与同源双侧区间，且区间置信水平为 1−α 时，才将“是否包括零假设”与检验作对照。差值零点为 0，比值为 1，回归系数在模型连接尺度上核对。单侧、调整/未调整、等效性界值、离散检验、不同区间构造及端点舍入均可能使简单对照失效。仅报告 p<0.05 时不要编造精确 p。零附近或边界上的舍入不支持认定冲突。
- 对完整配对差值（保持固定差值方向），`check.py paired d1 d2 ...` 给均值、样本标准差、标准误、t 与 df，零假设是平均差为零。使用前核对每个数能追到一个独立对象的完整一对。只有两组边际标准差时，配对协方差未知，不能重建配对标准误。Welch 的 df 可非整数，混合模型或稳健估计的 df 取决于方法。不要把一种模型的自由度套到另一种模型。公式可查 [NIST 配对观测](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)。
- 需精确复算且环境提供相应软件时，记录实际调用、模型参数、公式、分组顺序、缺失处理以及结果。统计显著性与实际重要性分别报告；声称等效/非劣需要预设界值和相应区间。图上估读只按图像精度报告；表格 OCR 的列顺序、负号、指数和小数点须复看页图。

**定位工具。** `check.py locate 逐页文本 引文` 显示文件、物理页、起止行。输入 UTF-8，可以有 BOM；分页符为换页符。工具忽略连续空白的差异，保留大小写、符号与数字。多处命中需延长引文、补表头或给人工可识别坐标。跨页内容分开定位；图片证据保留页/图/面板和人工复核结果。工具只定位，不能证明引文解释正确。无命中返回码 1；输入缺失或无效返回 2。
